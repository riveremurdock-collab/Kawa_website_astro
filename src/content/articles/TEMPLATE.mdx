Write the post here in plain paragraphs, same as always. Leave a blank

Every photo needs one `import` line up top, like the two above. The blocks
themselves (Photo, Gallery, RouteMap, the Instagram ones) don't need
importing — they're always available. See src/content/BLOCKS.md for the
full list.

Leave a blank line above and below every block, and note that `src` takes
the imported name in curly braces, not a filename in quotes:

<Photo src={myPhoto} alt="Brief factual description of what this image shows" />

Two or more photos together go in a Gallery, which scales them to a shared
height and fills the width. Any mix of orientations is fine:

<Gallery images={[
  { src: myPhoto, alt: "Brief factual description of what this image shows" },
  { src: secondPhoto, alt: "Brief factual description of what this image shows" },
]} />
